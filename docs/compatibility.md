# 兼容性与已知限制

当前开发基线：0.1.0-dev.10，Windows 11 x64，Electron 45.2.3，主要实测环境4K显示器/175%系统缩放。平台页面可能改版；已有样本通过不等同所有房间和账号永久兼容。

## 已有证据

- 三平台原生直播、登录、账号可用高清与原生聊天已有真实短时操作或现场确认。
- 多路发声、独听、布局/放大保持声音选择已有现场确认。
- 自然1–9路布局有离线/原生容器检查；三平台各三间同时1080P有一次短时可见观察。
- 历史、主播昵称、重启和旧组合补入有自动化与隔离原生界面验证；昵称未知时回退房号。
- 打包程序在源码树外用独立临时配置进行首次/重启/存储迁移检查。

## 尚未通过或仍待查明

- 虎牙控件自然隐藏后，再次整理/放大还原的修正仍需完整真实前台复验。
- 曾有斗鱼观看中重载后登录变化/降清报告，原发生瞬间未记录，尚未归因；不能宣称已修复。
- 九路“5分钟预热＋60分钟采集”持续高清性能尚未通过，不能承诺任意机器九路流畅。
- 稳定6路布局、重叠聊天输入命中、完整键盘与系统缩放/跨屏/睡眠恢复矩阵仍需补齐。
- 整理小窗中的统一音量/清晰度/飘屏控件和逐房间长期播放偏好尚未实现；目前使用平台原生入口。
- B站等平台的匿名昵称接口可能受限，无法确认时保留房号，不使用直播标题猜名字。
- 当前是未签名文件夹包，无安装器或自动更新。

## 证据分类

单元测试验证代码边界；本地生成页面验证原生容器和UI；匿名官方接口验证公开身份；实际账号/播放/声音/性能分别需要真实验证。自动测试数量不能替代尚未完成的真实验收。
